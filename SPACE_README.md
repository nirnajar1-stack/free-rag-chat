# Free RAG Chat (Hugging Face Space)

This Space runs the Streamlit RAG app from this repository.

1. Add a Space secret: `GROQ_API_KEY` = your key from https://console.groq.com/keys  
2. Optional: `DOCS_FOLDER_PATH` = `data/docs`  
3. Open the app → **Re-index / Sync Documents** in the sidebar  

Full docs: see the main repository `README.md`.
