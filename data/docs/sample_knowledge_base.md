# Sample Knowledge Base

This is a sample document for testing the Free RAG system.

## Product Overview

AetherDesk is a fictional project-management tool designed for small engineering teams.
It focuses on three pillars: **clarity**, **async updates**, and **lightweight planning**.

### Key Features

1. **Kanban boards** with WIP limits per column.
2. **Weekly async standups** that compile into a shared digest.
3. **Decision log** — every important choice is recorded with owner, date, and rationale.
4. **Doc links** — every card can attach Markdown specs stored in the team Drive folder.

## Onboarding Steps

1. Create a workspace named after your team.
2. Invite members via email.
3. Import an existing backlog CSV, or start from the blank board template.
4. Enable the weekly async standup reminder (Fridays 10:00 local time).

## FAQ

**Q: Does AetherDesk integrate with GitHub?**  
A: Yes. Link a repository in Settings → Integrations to auto-attach PRs to cards.

**Q: Can I export data?**  
A: Yes. Workspace admins can export boards and the decision log as JSON or CSV.
